# Changelog

## 0.1.1 (2026-11-08)

- "More free viewers" now starts with the Zovo extensions most related to this one. Picking one opens its Marketplace page, where you choose to install it.
- The README has a "Support Zovo" section with GitHub Sponsors and the developer's GitHub profile, and "More tools by Zovo" lists related extensions.
- The "More free viewers" list and the README now use the current Marketplace names and include the newest Zovo extensions: ZIP, GCode, EPUB, HAR, font and audio viewers.

## 0.1.0 (2026-11-07)

- First release.
- Opens .ttf, .otf, .woff, .woff2, .ttc and .otc files in a read-only editor.
- Type tester with sample text, a size slider and a waterfall of sizes.
- Variable font axes with sliders and named instances. OpenType feature toggles such as liga, kern, calt and ss01.
- Glyph grid with every glyph, search by name, character, U+ code point or glyph id, and copy buttons.
- Character map by Unicode block with coverage counts.
- Info tab with the name table, license and embedding fields, metrics, tables and a ready CSS @font-face rule.
- Support links (Sponsor, More free viewers) in the status line. You can hide them with fontViewer.showSupportLinks.
- One-time rating prompt after a few days of use. Turn it off with fontViewer.askForRating.
