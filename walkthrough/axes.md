## Axes and features

For a variable font, each axis gets a slider (weight, width, slant, optical size or a custom axis). Pick a named instance to jump to it.

Each OpenType feature in the font gets a check box. Features that browsers turn on by default, like `liga`, `kern` and `calt`, start checked. Turn on `ss01`, `zero` or `frac` to see what they change.

The Copy CSS button puts the @font-face rule plus your current `font-variation-settings` and `font-feature-settings` on the clipboard.
