## Every glyph, also the hidden ones

The Glyphs tab draws each glyph from its outline in the file. Ligatures, alternates and other glyphs that no character maps to are listed too.

- Type a name (`ss01`), a character (`€`), a code point (`U+20AC`) or a glyph id (`#42`) in the search box.
- Click a glyph to see it large with the baseline, x-height, cap height and advance width.
- Copy the character, the code point, a CSS escape, the glyph name or the outline as SVG.
