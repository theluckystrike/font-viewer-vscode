## License, credits and CSS

The Info tab starts with the license, license URL, copyright, designer and the embedding rights from the OS/2 table, so you can check a font before you ship it.

Below that are the metrics, the variable axes and instances, the feature tags, the full name table and every table with its size.

The @font-face rule uses the file name, the weight range of a variable font and a unicode-range built from the font's character map.
